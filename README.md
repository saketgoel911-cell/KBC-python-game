# KBC Python Quiz Game 🎙️

A beginner-friendly, text-based version of *Kaun Banega Crorepati*, built using Python.

## Features
- 10 multiple-choice questions
- Typewriter-style text animation
- One-time 50:50 lifeline
- Prize money tracking
- Input validation
- Option to quit after a correct answer
- Play-again feature
- Hinglish host messages and roasts 😂

## Concepts Practiced
- Functions
- Lists and dictionaries
- Loops and conditionals
- User input and validation
- Return values
- Basic program flow

## How to Run
1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run:


python kbc.py
